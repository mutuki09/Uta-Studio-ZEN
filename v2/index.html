歌詞を書く

歌詞の代わりに、フレーズの長さと区切りを自動で決めてメロディを作ります。メロディは「メロディ」の楽器が演奏します。

[Aメロ] [Bメロ] [サビ] の行でセクションを決められます（なくても自動で決めます）。読めない漢字は 未来(みらい) のように読みを書きます。改行がフレーズの切れ目、空白・読点が言葉の切れ目です。

MIDIは全パート（歌詞つき）。MusicXMLはNEUTRINOなどの歌声合成へ。WAVは物理モデル音源でそのまま書き出します。

ブラウザだけで動作・外部通信なし・録音素材なし（楽器はすべて振動を計算して鳴らしています）

使い方

  1. 歌詞を書く — 改行ごとに歌のフレーズ。[サビ] などでセクションを指定できます。
  2. 雰囲気を選ぶ — テンポ・コード進行・楽器・ノリがまとめて決まります。
  3. 3つの曲案をつくる — A・B・Cを聴き比べて選びます。
  4. 整える — 楽器やノリを変えると、その楽器らしい弾き方で伴奏を組み直します。
  5. 保存 — MIDI・MusicXML・WAV・プロジェクト。

構成：前奏（サビのメロディを楽器で）→ Aメロ → Bメロ → サビ → 後奏 → 終止。

AI設計図で曲を開く

  1. 指示文をコピー — 上の歌詞と雰囲気が入った指示文です。
  2. AIに貼る — Claude・ChatGPT・Gemini などのチャットに貼って送ります（このアプリは通信しません）。
  3. 返ってきたJSONを貼る — 下の欄に貼って「この設計図で開く」。

AIが作曲（構成・コード・メロディ・編成・キメ）を書き、このアプリが物理モデル音源で演奏します。
