# 歌スタジオ ZEN

[紹介動画を見る](https://mutuki09.github.io/Uta-Studio-ZEN/introduction.html) · [動画をGitHubから保存](https://github.com/mutuki09/Uta-Studio/releases/tag/intro-video-20260912)

紹介動画はZEN版と通常版をまとめたものです。歌声自動生成・音声分離・MV制作の実演は、追加エンジンを設定した通常版の機能です。動画本体は通常版のGitHub Releasesに置いています。

[ブラウザで使う](https://mutuki09.github.io/Uta-Studio-ZEN/) · [コード](https://github.com/mutuki09/Uta-Studio-ZEN)

日本語歌詞から3つの曲案を作り、試聴、音程・伴奏の調整、MIDI・MusicXML・プロジェクト保存を行う音楽制作Webページです。通常版から独立したZEN Studyコンテスト向けの静的版です。

PC・スマートフォンのGoogle Chrome向けです。歌詞には必要に応じて `未来(みらい)` のように読みを付けてください。最初から入っている短い歌詞ですぐに試せます。

## 使い方

1. `index.html` をChromeで開き、曲名と歌詞を入力します。
2. 雰囲気を選んで3案を生成し、近い案を再生します。
3. メロディや伴奏を調整し、MIDI・MusicXML・プロジェクトとして保存します。

AI向けの設計図用指示をコピーして、CodexやClaudeなどへ手動で作曲を依頼する使い方にも対応します。AIへの自動送信はありません。

## 提出版について

ブラウザ標準機能で動作し、外部JavaScriptライブラリ、SoundFont、NEUTRINO本体を同梱しません。通常版の歌声生成・音声分離機能は含みません。`serve.mjs` は開発用の任意サーバーで、公開ページの実行には不要です。

入力は歌詞・MIDI・AI設計図JSON・専用プロジェクト、出力はMIDI・MusicXML・WAV・専用プロジェクトです。MusicXMLはこの版では書き出しのみです。作成済みの歌声WAVを読み込んで伴奏と合わせることもできます。歌声の自動生成には別のPCソフトが必要です。

## スマホでの操作

再生ボタンを押すと音声が開始します。音量と端末の消音設定も確認してください。譜面は左右へスクロールできます。細かい音符のドラッグが難しい場合は「もっと細かく調整」の高さ変更ボタンを使えます。ダウンロードしたファイルの場所は端末のファイルアプリで確認してください。

## 公開・データの取り扱い

GitHub Pagesではリポジトリのルートを公開します。相対パスで読み込むため、サブディレクトリ配置にも対応します。歌詞や読み込んだファイルを外部へアップロードする処理はありません。AIへの依頼は利用者が別サービスで行います。利用するAI側の条件は各サービスに従ってください。

第三者の書籍本文・画像・音源・ライブラリは同梱していません。自作コードへの新たなオープンソースライセンスは現時点で付与していません。

テストは `node test.mjs` で実行します。元版との比較も実行する場合のみ、環境変数 `AI_SCORE_ORIGINAL_DIR` に元版のフォルダを指定してください。

`index.html` をブラウザで開けます。`compare.html` では同じ音色・テンポ・ベースの4小節をA/B比較できます。

作曲画面の「理論補助／従来の処理」は次の作曲・伴奏再生成と診断から反映。既存の曲を切替だけで変更しません。取り込んだ原曲への自動適用もありません。プロジェクトの音符は従来形式で保存。方式の選択は保存されず、新しく開くと理論補助が初期値です。

## 変更

- 伴奏: 和音の構成音を保ち、前の配置に近い転回形を探索。ベース・ドラム・メロディ・タイミングは同じ。
- 診断: 調外音を自動的にエラーにせず参考警告へ。短い弱拍の連続した音について経過音／隣接音の候補を表示。和声の正しさを保証する分類ではありません。
- 理論補助での修復: 調外音の音階への吸着を無効化。他の既存修復は維持。
- 厳密な四声体禁則、転調推定、掛留の判定、フレーズ構成の生成は今回の対象外。

参考: [総合和声の出版社紹介](https://www.ongakunotomo.co.jp/catalog/detail.php?id=102330)、[SoundQuestの方針](https://soundquest.jp/about-limuth/)、[コード編](https://soundquest.jp/category-archive-chord/)。書籍本文・図版・譜例・サイト音源の転載はなく、今回のルールと比較例は自作です。教材の全体系を実装したものではありません。

検証: `node test.mjs`。C→Am→F→Gの移動コストは41→9。これは音楽品質のスコアではありません。構成音の保持、元版との従来モード一致、ベースとドラムの保持、診断による入力非変更、調外音の保持、音符重複エラーの維持を確認。
