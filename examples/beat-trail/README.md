# BEAT TRAIL TURBO

紹介動画のゲーム実例です。index.html をブラウザで開いて遊べます。
4倍スタート、40秒で15倍。3レーンを左右キーまたはA/Dで移動します。Escで休憩。
自動再生はせず、「音楽と走りだす」で音とゲームを開始します。

素材：Kenney Nature Kit / Platformer Kit（58種類・CC0）。恐竜はこの作品のオリジナル。
BGM：オリジナル曲「Mint Overdrive」（6楽器）、GeneralUser GS 2.0.3による演奏。
詳細：[動画と素材のクレジット](../../videos/credits.md)。
